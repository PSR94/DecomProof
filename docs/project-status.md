# Project status — v0.1.0 development

## Implemented

- typed target identifiers and stable fingerprints
- universal evidence structure with stable content IDs and raw hashes
- deterministic hard-blocker/policy/scoring/verdict pipeline
- observation-window sufficiency and dynamic evidence freshness
- conservative temporal pattern inference
- evidence-linked dependency graph model
- workspace scanning for common source/config file families
- offline generic JSONL runtime/data/event evidence ingestion
- hashed consumer identifiers
- versioned retirement proof schema and JSON/terminal/Markdown report primitives
- CLI initialization, scanning, ingestion, analysis, proof, graph, blocker and verification commands
- AtlasCommerce source/evidence snapshots for staged decommission analysis

## Partial / experimental

- JavaScript/TypeScript and Python scanning is heuristic rather than full AST-semantic analysis.
- OpenAPI, Terraform, Kubernetes, SQL and GitHub Actions scanning is structural/text-assisted and classified by evidence confidence.
- Post-removal verification currently evaluates imported verification/leftover evidence; correlated error-rate analysis is not yet implemented.
- Dashboard and API are developer-preview surfaces, not a hosted multi-tenant service.

## Roadmap-only for v0.1

- direct Datadog/CloudWatch/Grafana/Snowflake/BigQuery integrations
- destructive cleanup automation
- AI-generated verdicts (deliberately not planned)
