# AtlasCommerce demo script

1. Run `make demo-stage-0`. Inspect `retirement.proof.json`; the scanner should discover schedule, contract, SDK, infrastructure and SQL references while imported evidence records active HTTP, database and event use.
2. Compare the staged source/evidence snapshots through stage 3 to see specific blockers disappear.
3. Run `make demo-ready`; only historical documentation and zero-activity dynamic evidence remain, with a sufficient runtime window.
4. Run `make demo-verify`; stage 5 intentionally contains a cleanup leftover and should report `partial-cleanup`.
5. Run `./scripts/demo.sh 6` for the clean verification snapshot.

The demo does not hardcode a readiness result; each proof is generated by the same scanner, ingestion and policy code used by the CLI.
