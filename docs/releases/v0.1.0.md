# DecomProof v0.1.0 release notes (candidate)

DecomProof 0.1.0 introduces the versioned retirement proof, deterministic policy/verdict engine, evidence model, workspace scanner, offline telemetry import, temporal reasoning, dependency graphs, AtlasCommerce demonstration fixtures, CLI, and post-removal verification model.

This is a **release candidate document**, not evidence that a GitHub Release has been published. See `docs/project-status.md` and `docs/release-checklist.md` for the current validation state.
