# Code of Conduct

We are committed to a respectful, harassment-free project environment for everyone. Be constructive, assume good faith while still challenging technical claims, and focus criticism on ideas and evidence rather than people.

Unacceptable behavior includes harassment, threats, discriminatory language, doxxing, sustained disruption and publishing private information without permission. Maintainers may edit, remove or reject contributions and interactions that violate these expectations.

Report conduct concerns privately to the project maintainers through GitHub where possible.
